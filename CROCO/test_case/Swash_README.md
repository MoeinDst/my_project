# CROCO/SWASH reference test case

This folder collects reference figures used while inspecting the laboratory-scale CROCO/[SWASH](https://croco-ocean.gitlabpages.inria.fr/croco_doc/model/model.test_cases.swash.html) benchmark that informed subsequent model adaptation.

I have experimented with the GLOBEX experiments from [Michallet et al. 2014](https://hal.science/hal-01084718), and found out that the benchmark figure is associated with B2 experiment rather than B3 as explained on the website. Feel free to try on your own.

Anyways, the **CROCO** documentation and associated figures, along with the GLOBEX experiment should be checked carefully for consistency of experiment labels (notably B2 versus B3) before attempting exact reproduction.
