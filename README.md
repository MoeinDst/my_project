## About this repository

This repository puts together selected scripts, notebooks, and, in some cases, configuration files from different projects I've worked on.

My work has involved numerical ocean models dealing with **physical oceanography**, **coastal hydrodynamics**, and **sediment transport**, as well as handling, processing, and analysing **field measurements** and **large oceanographic datasets** collected during research campaigns.

I'm keeping some of that work here to make it easier to find and share, and to give a glimpse of the tools and workflows I've used along the way. The projects range from setting up and running ocean models to working with observational data, processing model outputs, and visualising results.

## What's inside?

| Directory / file | What's in it |
| --- | --- |
| **[CROCO](CROCO/)** | Scripts and configuration files for coastal hydrodynamic and sediment transport modelling, including model setup, pre-processing, and post-processing. |
| **[ROMS](ROMS/)** | Scripts and tools for working with the Regional Ocean Modeling System (ROMS). |
| **[ADCP](ADCP/)** | Scripts for processing and analysing Acoustic Doppler Current Profiler (ADCP) measurements. |
| **[Baltic SST notebook](baltic_sst_yearly_comparison.ipynb)** | A standalone notebook for comparing yearly sea surface temperature data in the Baltic Sea. |

The project folders have their own READMEs with more detail about the scripts, their context, and how they were used.

## Tools and workflows

Depending on the project, I've mainly used **Python**, **MATLAB**, and **shell scripting**, alongside ocean models such as **ROMS** and **CROCO**. The scripts cover things like preparing model inputs, processing field measurements, analysing simulation outputs, and making plots and visualisations.

Some scripts were written for a particular project or modelling setup; others can be adapted to similar tasks.

## A few things to keep in mind

This is a selection of work from larger projects, rather than a complete package for reproducing every simulation or analysis. Some scripts need external datasets, model installations, or project-specific paths and settings. I've added more context in the individual READMEs where possible.
